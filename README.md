# Wildflower Bakery Landing Page

A responsive landing page for a bakery concept, built from scratch with semantic HTML5 and CSS3.

> **Concept project.** This is a practice project. The copy and testimonials are sample content.

**[View the live site](https://wildflowerlandingpage.netlify.app)**

## What it includes

- A welcoming hero section with a clear call to action
- An "Our Story" section introducing the bakery
- Menu sections for pastries, desserts and beverages
- A customer testimonials section
- A contact section

## Built with

- **HTML5**: semantic page structure
- **CSS3**: layout with Flexbox and CSS Grid, adapting across mobile, tablet and desktop screens

## What I practised

- Structuring a full landing page with semantic sections
- Building a layout that adapts cleanly from phone to desktop
- Writing clear, readable copy and a logical content order

## Planned improvements (v2)

- A full redesign with a stronger visual identity and real imagery
- Smooth in-page navigation to each section
- An accessibility pass: colour contrast, focus states and alt text
- Before and after comparison to show how my skills have progressed

## Run it locally

There's no build step. Clone the repo and open `index.html` in your browser:

```bash
git clone <your-repo-url>
cd <your-repo-folder>
```

Then open `index.html`, or use the Live Server extension in VS Code.
